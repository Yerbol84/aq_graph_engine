#### День 1-2: Реализация Join Strategies в движке

**Задачи:**
1. Добавить enum `JoinStrategy` в `aq_schema`
   ```dart
   enum JoinStrategy {
     firstCome,  // Выполнить при первом ребре (текущее поведение)
     waitAll,    // Дождаться всех входящих рёбер
     exclusive,  // Первое ребро блокирует остальные
   }
   ```

2. Добавить поле `joinStrategy` в узлы
   ```dart
   class WorkflowNode {
     final JoinStrategy joinStrategy;
     // ...
   }
   ```

3. Реализовать логику в `PolymorphicGraphEngine`
   ```dart
   // Добавить Map для отслеживания прибывших рёбер
   final Map<String, Set<String>> _arrivedEdges = {};

   // Логика waitAll
   if (node.joinStrategy == JoinStrategy.waitAll) {
     _arrivedEdges[nodeId] ??= {};
     _arrivedEdges[nodeId]!.add(edgeId);

     if (_arrivedEdges[nodeId]!.length < incomingEdges.length) {
       _log('⏳ Node [$nodeId] waiting for ${incomingEdges.length - _arrivedEdges[nodeId]!.length} more edge(s)');
       return; // Не выполнять узел
     }

     _log('✅ All ${incomingEdges.length} edges arrived at [$nodeId]');
   }
   ```

4. Добавить логи для отладки

**Результат:** Diamond patterns работают корректно

**Effort:** 2 дня

#### День 3-4: Unit тесты для Join Strategies

**Задачи:**
1. Создать Mock узлы с счётчиками выполнений
2. Тесты на `waitAll`:
   - Узел ждёт все рёбра
   - Узел выполняется ОДИН раз
   - Логи корректны
3. Тесты на `firstCome`:
   - Узел выполняется при каждом ребре

4. Тесты на `exclusive`:

   - onError не выполняется если onSuccess прошёл
5. Негативные тесты:
   - Deadlock с waitAll
   - Циклический граф
