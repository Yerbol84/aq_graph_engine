## 💡 КЛЮЧЕВЫЕ ПРЕИМУЩЕСТВА E2E

### 1. Имитация Production

E2E тесты запускаются в **точно таком же окружении** как production:
- Те же Docker образы
- Та же сетевая конфигурация
- Те же переменные окружения

### 2. Изоляция

Каждый запуск тестов создаёт **чистое окружение**:
- Свежая БД
- Нет конфликтов с локальными сервисами
- Нет side effects между запусками

### 3. Проверка HTTP API

Integration тесты используют прямые вызовы функций.
E2E тесты используют **реальные HTTP запросы** через API.

### 4. CI/CD Ready

E2E тесты легко интегрируются в CI/CD:
```yaml
- name: Run E2E tests
  run: docker-compose -f docker-compose.test.yml up --abort-on-container-exit
```

## 🎓 ЛУЧШИЕ ПРАКТИКИ

### 1. Запускайте перед каждым PR

```bash
make test-e2e
```

Это гарантирует что код работает в production-like окружении.

### 2. Добавьте в CI/CD

```yaml
# GitHub Actions
- name: E2E Tests
  run: |
    cd pkgs/aq_graph_engine/test/e2e
    docker-compose -f docker-compose.test.yml up --build --abort-on-container-exit
```

### 3. Проверяйте логи при падении

```bash
docker-compose -f docker-compose.test.yml logs
```

### 4. Очищайте после тестов

```bash
docker-compose -f docker-compose.test.yml down -v
```

Флаг `-v` удаляет volumes, освобождая место.

### 5. Используйте отдельные порты

E2E тесты используют порты 5433, 8766, 8082 чтобы не конфликтовать с локальными сервисами на 5432, 8765, 8081.

## 🔄 ИНТЕГРАЦИЯ С СУЩЕСТВУЮЩИМИ ТЕСТАМИ

### Пирамида тестирования

```
        E2E Tests (Docker)
       /                  \
      /    Медленные       \
     /     Дорогие          \
    /      Полный стек       \
   /___________________________\

  Integration Tests (Local)
 /                            \
/      Средние                 \
\      Компоненты + БД         /
 \____________________________/

        Unit Tests
       /          \
      /  Быстрые   \
     /   Дешёвые    \
    /    Изоляция    \
   /__________________\
```

### Когда использовать каждый уровень

**Unit тесты:**
- Логика движка (join strategies)
- Алгоритмы
- Утилиты

**Integration тесты:**
- Работа с БД
- Логи
- Порядок выполнения

**E2E тесты:**
- HTTP API
- Полный стек
- Production-like окружение
