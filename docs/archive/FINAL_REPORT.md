## Архітектурні принципи

Пакет тепер повністю відповідає архітектурним принципам:

### ✅ Розділення client/server
- Клієнт: `lib/aq_graph_engine.dart` — тільки клієнтські компоненти
- Сервер: `lib/server.dart` — серверні компоненти + клієнт

### ✅ Тонкий клієнт
- Клієнт не має доступу до `GraphEngine`, `NodeTypeRegistry`, `Metrics`
- Клієнт працює тільки через `GraphEngineClient` + транспорт

### ✅ Правильна структура
- `src/client/` — клієнтська частина
- `src/server/` — серверна частина
- `src/shared/` — спільні утиліти
- `src/interfaces/` — інтерфейси (доступні всім)
- `src/transport/` — транспорт (mixed)

### ✅ Універсальний інтерфейс інструментів
- `AQToolService.instance.callTool()` — єдина точка входу
- Mock реалізація для тестів
- Легко розширювати новими інструментами
