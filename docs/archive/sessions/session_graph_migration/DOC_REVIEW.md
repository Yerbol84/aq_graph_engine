## 2. Критика

### Проблема 1: Документация описывает то, чего уже нет

`GRAPH_ENGINE_GUIDE.md` учит добавлять узлы через фабрику:
```dart
// Добавить в фабрику в pkgs/aq_graph_engine/lib/src/factories/:
case 'myCustom':
  return MyCustomNode.fromJson(json);
```
Фабрики (`WorkflowNodeFactory`, `InstructionNodeFactory`) — в процессе удаления.
Правильный путь — `NodeTypeRegistry`. Документ вводит в заблуждение.

### Проблема 2: README ссылается на несуществующие файлы

```
- [PromptGraph](./PROMPT_GRAPH.md)          ← файла нет
- [Архитектура движка](./ARCHITECTURE.md)   ← файла нет
- [Создание кастомных узлов](./CUSTOM_NODES.md) ← файла нет
- [Разработка воркеров](./WORKERS.md)       ← файла нет
```
Версия документации: `2026-04-11`, статус: `Production Ready (100%)` — это неправда.

### Проблема 3: Нет единого актуального технического документа

Актуальное состояние архитектуры разбросано по:
- `audit_2026_05_02/AUDIT_REPORT.md` — что сломано
- `audit_2026_05_02/POST_AUDIT_RESOLUTION_PLAN.md` — что планировалось исправить
- `session_state_contracts/REPORT.md` — что исправлено
- `session_graph_migration/PROGRESS_REPORT.md` — что в процессе

Нет одного документа: "вот как система работает сейчас".

### Проблема 4: Сессионные документы смешаны с постоянной документацией

`docs/` содержит и постоянную документацию (`OVERVIEW.md`), и сессионные отчёты (`session_*/`).
Читатель не понимает что актуально, а что исторический артефакт.

### Проблема 5: `archive/` — свалка без структуры

30+ файлов без индекса. Невозможно найти нужное.
Большинство описывают состояние до рефакторинга — вводят в заблуждение.

### Проблема 6: Аудит зафиксировал проблемы, но не все решены

`AUDIT_REPORT.md` описывает BUG-1..4, ISSUE-1..6, ARCH-1..3.
Из них реально решены в последующих сессиях:
- ✅ BUG-2 (дублирование логов при suspend) — убран параметр `logs` из `suspendRun`
- ✅ BUG-3 (projectPath) — временный костыль через `graphSnapshot`
- ✅ BUG-4 (двойной write) — guard в `updateRunLog`
- ✅ ISSUE-2 (GraphTraversal + repo) — заменён на callback
- ✅ ISSUE-5 (_short() дублируется) — вынесен в `shared/logger.dart`
- ✅ ARCH-1 (IRunStateManager vs IRunRepository) — задокументировано
- ✅ ARCH-2 (GraphTraversal знает о repo) — решено через callback
- ✅ ARCH-3 (нет интеграционных тестов) — добавлен `data_layer_run_repository_test.dart`
- ⚠️ BUG-1 (appendLog fire-and-forget) — `appendLog` добавлен, но `.ignore()` убран
- ❌ ISSUE-1 (tryAcquireLock заглушка) — не решено, TD-2
- ❌ ISSUE-4 (InstructionRunner toJson/fromJson) — в процессе (текущая сессия)
- ❌ ISSUE-6 (cleanupDLQ soft delete) — не решено

Нет документа который отражает актуальный статус аудита.
