# План разработки AQ Graph Engine

## 🎯 Цель

Создать production-ready систему выполнения графов с клиент-серверной архитектурой.

**Результат:** Можем запускать Workflow графы из Flutter приложения через удалённый сервер.

## 🚀 Быстрый старт (для разработчика)

### Сегодня (День 1)

1. **Создать структуру проекта:**
   ```bash
   cd pkgs/aq_graph_engine
   mkdir -p server_apps/graph_engine_server/{bin,lib/server/handlers}
   ```

2. **Добавить зависимости:**
   ```yaml
   # server_apps/graph_engine_server/pubspec.yaml
   dependencies:
     shelf: ^1.4.0
     shelf_web_socket: ^1.0.0
     aq_schema:
       path: ../../aq_schema
     aq_graph_engine:
       path: ../..
   ```

3. **Создать базовый сервер:**
   ```dart
   // bin/main.dart
   void main() async {
     final server = GraphEngineServer();
     await server.start(port: 8080);
     print('Server running on http://localhost:8080');
   }
   ```

4. **Запустить:**
   ```bash
   dart run bin/main.dart
   ```

5. **Проверить:**
   ```bash
   curl http://localhost:8080/health
   # Ожидаем: {"status": "ok"}
   ```
